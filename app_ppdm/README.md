# PPDM - Programação para Dispositivos Móveis

## Parte 1

### Diferença entre desenvolvimento Nativo e Cross-Platform

O desenvolvimento nativo utiliza linguagens específicas para cada sistema operacional, como Kotlin/Java para Android e Swift para iOS. Já o desenvolvimento Cross-Platform, como o Flutter, permite desenvolver um único código que funciona em diferentes plataformas.

### Diferença entre StatelessWidget e StatefulWidget

O StatelessWidget é utilizado quando a interface não sofre alterações após ser criada.

O StatefulWidget é utilizado quando a interface pode ser alterada durante a execução do aplicativo, como em um contador.

### O que acontece quando usamos setState()?

O método `setState()` informa ao Flutter que o estado do widget foi alterado, fazendo com que a interface seja reconstruída e atualizada com as novas informações.
